# 方法对照试跑

2026-11-16，两位独立代理分别读取旧版和候选方法，执行相同的两项任务。产物为实际生成的文案、视觉配方及提示词。输入文件和产物的摘要见 inputs.json。原始产物保留代理自检，以下复核与其分开。

## 共同任务条件

事实底稿为虚构研发案例。电机和传动机构产生夹紧力，台架记录指令、位置和夹紧力。当前没有寿命、响应时间、SIL及商业成熟度数据。草稿包含行业颠覆、更安全与精准控制等缺少证据的说法。审校保留作者的工程判断、核对指令与响应的目标，以及后续故障和长期测试。

- A 为微信中文短文，标题含标点不超过 20 字，正文 150 至 250 字。封面为 3:4 单墨，逐字文案为「制动状态如何验证？」。
- B 为 LinkedIn 英文短文，正文 100 至 150 词，保留第一人称工程判断。封面为 4:3 单蓝墨，逐字文案为「Make braking observable」。
- 两例封面均为概念夹钳。缺少内部结构资料，只表达外观。任务止于配方和提示词，不生图或发布。

两个样本不能证明普遍效果或视觉质量提升。未测延迟、模型成本和连续重试的一致性。上述字数、输入摘要、产物摘要和配方关联由 tests/test_cases.py 复算。修改工具与方法后仍需新任务试跑，重放已有产物仅证明已有证据没有漂移。
